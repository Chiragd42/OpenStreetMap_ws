After setting up the project folder, place any regional or country .osm.pbf dataset inside data/pbf.


The -> make prep command automatically finds the first .osm.pbf file, parses it, and creates a matching cache.
For an explicit dataset use -> make prep DATASET=my-region PBF=/path/to/my-region.osm.pbf
Germany is opt-in (large download): after obtaining the PBF, use -> make prep-germany PBF=data/pbf/germany-latest.osm.pbf
Validate Kiel with -> make validate-kiel CACHE=data/cache/germany.bin

First, open a terminal and run-> make prep

Once the preparation is complete, start the backend server with-> make server

Finally, open a second terminal and launch the frontend with-> make ui

open broswer and use url for gui  -> "http://127.0.0.1:5500/frontend/index.html"


GUI Instructions: 

- Move or zoom the map to load houses, streets, and regions.
- To use reverse geocoder, click "Reverse Mode: ON".
- Then click anywhere on the map.
- The nearest address will be shown with a marker, line, popup, and result box.
